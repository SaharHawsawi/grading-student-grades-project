# grading students grades project
Student Grade Management System is a JavaFX application designed to help professors manage student names and grades. The system allows professors tools in, add students, assign grades, edit existing grades, and save student records to a file for future access.

# About the project
A JavaFX desktop application designed to streamline student registration, grade management, and academic performance tracking. Built using standard Java, JavaFX components, and FXML layouts, the application uses local flat-file storage (students.txt) to process and store records dynamically without requiring external database engines.

# 🚀 Key Features

* Secure Role-Based Access Control: Built-in authentication screen validating unique credentials for authorized academic staff members.
* Dynamic Student Enrollment: Simple, input-validated registration interface that immediately flushes new student records to the local data layer.
* Targeted Grade Input Evaluation: Contextual grading pipeline that verifies whether a student ID exists before injecting or overwriting numeric scores.
* Interactive Live Data Tables: Utilizes JavaFX TableView framework driven by custom SimpleStringProperty objects to sync file datasets cleanly onto user layouts.
* Comprehensive Performance Metrics: On-the-fly analytics dashboard processing registered headcounts, grade point averages, as well as calculating highest/lowest boundaries seamlessly.

# Tech Stack & Architecture

* Core Language: Java
* UI Framework: JavaFX (with Scene Builder FXML styling wrappers)
* Storage Engine: Standard I/O Local Storage System (students.txt)
* Structural Design: Model-View-Controller (MVC) architectural separation

# ⚙️ Getting Started & Local Installation


Prerequisites

* Java Development Kit (JDK 11 or newer)
* JavaFX SDK configured with your IDE environment (NetBeans, IntelliJ, or Eclipse)

Steps to Run

1. Clone this repository directly onto your local machine:
2. Open the source project path within your preferred IDE.
3. Ensure that your IDE contains your JavaFX runtime compiler arguments pointing to the proper FX modules.
4. Execute App.java to start the program runtime sequence.
